# UT 2 · Elementos de amarre y fondeo

## 2.1 Elementos de amarre

| Elemento | Qué es |
|---|---|
| **Noray** | Poste corto y robusto en el muelle donde se encapillan las amarras. |
| **Muerto** | Bloque pesado (hormigón, piedra, hierro) en el fondo, al que se amarra una boya o una cadena para amarrar barcos. |
| **Boya** | Flotador fondeado; las de amarre van unidas a un muerto y tienen una argolla. |
| **Defensas** | Cilindros o bolas que se cuelgan del costado para que no roce con el muelle u otro barco. |
| **Bichero** | Palo con un gancho en la punta para coger cabos, boyas o separar el barco. |
| **Chicote** | Extremo de un cabo. |
| **Seno** | Parte curva de un cabo entre sus extremos (un "bucle" sin nudo). |
| **Firme** | Parte del cabo que está fija o trabajando (lo contrario del chicote libre). |
| **Gaza** | Lazo u ojo hecho en el extremo de un cabo (con nudo o costura). |
| **Guía-cabos** | Pieza (en la borda o la cubierta) por la que pasa un cabo para dirigirlo sin que roce. |
| **Roldana** | Rueda acanalada por la que pasa un cabo (la de una polea). |
| **Bitas** | Pareja de postes robustos en cubierta para hacer firmes las amarras. |
| **Cornamusa** | Pieza en forma de "T" o de cuernos para tomar vueltas a un cabo y hacerlo firme. |

- **Dar vuelta(s)**: pasar el cabo alrededor de un tambor, bita o cornamusa para que aguante.

## 2.2 Nudos

| Nudo | Para qué se usa |
|---|---|
| **Llano** | Unir por sus chicotes dos cabos **del mismo grosor**. |
| **Vuelta de rezón** | Amarrar un cabo a una argolla: la del ancla (rezón) o la de una boya. |
| **Ballestrinque** | Amarrar un cabo a un poste, candelero o pasamanos; p. ej. colgar las **defensas**. Se hace y deshace rápido. |
| **As de guía** | Hacer una **gaza fija que no se corre** ni se aprieta. Sirve para encapillar en un noray o para rescatar a una persona. |

## 2.3 Fondeo

**Elegir el lugar y el tenedero**

- Tener en cuenta: **dirección e intensidad del viento** (y su previsión), **profundidad**, **tipo de fondo**, **corrientes**, **abrigo** y **espacio para bornear** sin tocar a otros barcos ni a la costa.
- **Tenedero** = calidad del fondo para que agarre el ancla:
  - Buenos: **fango duro**, **arena**, arcilla.
  - Malos: **roca** (el peor: el ancla no se clava o se engancha), piedras, algas, praderas de posidonia (además está prohibido dañarlas).

**Fondeo a la gira con un ancla**

1. Llegar despacio al punto elegido, **proa al viento** (o a la corriente si manda más).
2. Con el barco parado (o empezando a ir atrás), soltar el ancla y **filar** cadena mientras el barco cae hacia atrás.
3. Cuando hay suficiente cadena, frenar y dar un poco atrás para que **el ancla se clave**.

- **Longitud del fondeo**: como orientación, **3 veces la profundidad** si es todo cadena y **unas 5 veces** si hay cabo. Con mal tiempo, más.
- **Círculo de borneo**: el barco "gira" alrededor del ancla al cambiar el viento. Su radio es aproximadamente la **longitud de cadena filada más la eslora**. Hay que dejar sitio para él.

**Garreo**: el ancla **no agarra bien y se desplaza por el fondo**; el barco se va con el viento.

**Vigilancia durante el fondeo**

- Tomar **marcas** o **enfilaciones** en tierra (o demoras) y comprobar que no cambian.
- **Alarma de sonda** (salta si cambia la profundidad) y alarma de fondeo del GPS.

**Orinque**: cabo con un **boyarín** amarrado a la **cruz del ancla**. Señala dónde está el ancla y permite zafarla tirando desde la cruz si se queda enganchada.

**Levar el ancla**

1. Arrancar el motor y avanzar despacio hacia el ancla mientras se **vira** cadena (sin que el molinete haga todo el esfuerzo).
2. Cuando la cadena está **a pique**, el ancla se desclava (**zarpa**).
3. Subirla, comprobar que viene **clara** y estibarla.

> **Molinete antes de fondear**: primero **apretar el freno y desembragar**; así se controla la salida de la cadena soltando el freno poco a poco.
